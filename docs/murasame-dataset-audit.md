## 标注噪声

标注由 `voice_clone_project/scripts/03_transcribe.py` 用 Whisper **small/tiny** 自动转写生成
（`~/.cache/huggingface/hub` 里只缓存了 small 与 tiny，没有 GUIDE.md 声称的 medium）。
用「每秒字符数」作为代理指标做的量化结果：

| 问题 | 条数 | 占比 |
|---|---|---|
| 低于 2.0 字/秒（漏字，如 10.8s 只标了「ん」） | 112 | 2.6% |
| 高于 14.0 字/秒（幻觉或多字） | 22 | 0.5% |
| 含重复假名 3 次以上（喊叫，无法作为文本目标） | 133 | 3.0% |
| 含拉丁字母（`www`、`Thank you, Mr.Suzo!`） | 24 | 0.5% |
| 以助词结尾（疑似截断） | 163 | 3.7% |
| 标注少于 5 字 | 213 | 4.9% |

### 两类典型错误

**1. Whisper 幻觉**
`ご視聴ありがとうございました`（YouTube 训练数据残留）出现在多条 0.3–0.8 秒的短切片上，
`Thank you, Mr.Suzo!`、`www` 同理。这些标注与音频完全无关。

**2. 系统性错词**
`我が敗` 出现 **97 次**，全部应为「我が輩」——丛雨的自称。同类还有：

- `我が範囲` → 我が輩
- `ダンジュ` → ダンジョン
- `ムラサメモギ` / `紫メマル` / `カキラ` → ムラサメマル / かけら
- `百分は一軒に近づかも言う` → 整句错乱

## 修复验证

用 `faster-whisper large-v3`（本地部署）+ 注入丛雨用语的 `initial_prompt` 重转写 76 条抽样，
对比旧标注：**75/76 发生变化**，且修正幅度明显大于 small 模型。

修正得到的内容（括号内为旧标注）：

- `ご主人` ← `ご視聴ありがとうございました`（多条 0.7 秒切片的 Whisper 幻觉）
- `我が輩` ← `我が敗` / `我が範囲` / `我が拝` / `我が牌`
- `小春、蓮太郎` ← `ごはる、レンタロウ`
- `黒月の巫女` ← `ロズキのみこ`
- `レナの先祖 … お主の家` ← `メナの戦争 … 本市の家`
- `切なそうな顔` ← `鉄なそうな顔`
- `生身の体` ← `なまみの体`
- `ケン十郎はツンデレ属性` ← `玄獣路を積んでる特性`
- `源十郎` ← `現住郎`

### 必须靠丢弃、而不是重转写解决的问题

`initial_prompt` 是双刃剑。在**非语音片段**（叹气、笑声、呼吸、喊叫）上，
large-v3 不输出空结果，而是**把提示词本身当成识别结果吐出来**：

| 切片 | 时长 | 重转写输出 |
|---|---|---|
| `mur309_132.wav` | 10.8s | `うむ、はっはっは、お館様、叢雨、ムラサメ。` |
| `mur317_166.wav` | 7.5s | `うむ、はっは、お主、ご主人、ぬし、であるぞ、うむ。` |
| `mur306_331.wav` | 5.6s | `ご主人、うむ、うむ、うむ。` |

这些正是旧标注为 `ん`、`お?`、`交渉で` 的片段 —— 内容本来就是非语音。
它们无法作为文本到语音的训练目标（不可能让模型从一声喊叫学会说一句话），
**只能丢弃，重转写救不回来**。
